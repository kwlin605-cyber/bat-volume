# 計畫資料夾

只有使用者要求「存計畫」或「存成計畫」時，才將已討論的目標、範圍、方案、步驟、驗收方式與待決事項存為這裡的 Markdown。命名可使用日期與主題，讓同一事項容易辨識。

保存計畫不代表授權實作；進行中工作的狀態與固定任務起點由 [目前交接](../交接/目前交接.md)保存，未開始或暫緩工作見 [待辦](../代辦/待辦與已知限制.md)。接續前須核對目前實作與差異，計畫可作背景，不能代替 Code、Tests 或已確認需求。

不自動搬移或刪除舊計畫。其他位置的草稿亦保留原位；各文件入口由 [專案導覽](../../README.md#專案導覽與閱讀順序)集中提供，不把未驗證的草稿列為正式契約。
