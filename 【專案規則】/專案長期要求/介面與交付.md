# 介面與交付要求

- 本專案的介面文案與使用者提示使用繁體中文。
- 網站功能或畫面交付前，確認本機已建置為本次版本，提供 [啟動.cmd](../../啟動.cmd) 連結與簡單操作及預期結果。純文件工作不為此重建網站；程式與必要技術檢查由 Agent 負責，驗收與同步依工作規則分別處理。

文字管理、樣式、元件共用及操作清楚等通用原則依 [開發偏好](../開發偏好.md#使用介面主題與語系)。樣式、文字資源位置與元件使用方式見 [UIUX 設計規範](../docs/UIUX設計規範.md)；各端操作契約見 [手機與電腦操作](../docs/手機與電腦操作.md)，保存時機見 [資料保存與設定](../docs/資料保存與設定.md)，輸出適配見 [報告與列印](../docs/報告與列印.md)，建置與發布見 [啟動、建置與部署](../docs/啟動建置與部署.md)。
