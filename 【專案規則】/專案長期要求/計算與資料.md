# 計算與資料要求

- 幾何核心、重量公式、格式、保存及呈現各負其責。手機、電腦與報告維持相同計算語意，不各寫一套公式；介面可有獨立狀態，不為共用而綁在一起。
- 完整輪廓是切線、裁切及後續幾何的來源。顯示網格只負責呈現，不反過來決定數據；不以固定間距取樣或有損刪點取代完整幾何。
- 計算、保存及排序保留原始精度，換算與取位在呈現邊界處理，不把顯示文字或四捨五入結果寫回原始數值。畫面及 renderer 沿用共用公式與格式能力。
- 無法判斷的數值維持未知，不以 0 或猜測資料冒充已知；可用的部分結果與診斷按既有契約保留。

目前的模組與擴充位置見 [架構總覽](../docs/架構與設計/架構總覽.md)；幾何模型及解析支援見 [ANC 與鋸片計算](../docs/功能、資料與契約/ANC與鋸片計算.md)，公式、單位與精度見 [切線、尺寸與重量](../docs/功能、資料與契約/切線尺寸與重量.md)，資料生命週期見 [資料保存與設定](../docs/功能、資料與契約/資料保存與設定.md)。

實機校準、支援指令與模型排除項目依 [待辦與已知限制](../代辦/待辦與已知限制.md)理解，不把計算模型或顯示位數當成實物認證。
