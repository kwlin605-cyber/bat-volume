# 切線、尺寸與重量

## 切線與裁切

統一入口為 [analyze.ts](../../../src/domain/analyze.ts)。有刀寬與 0 mm 模式都直接將完整輪廓交給切線策略；沒有固定間距掃描，也不將交界吸附到格線。

[terminal-stubs.ts](../../../src/domain/cuts/terminal-stubs.ts) 的 `terminal-first-rise` 規則分別從低 Y、高 Y 端往內檢查，略過定半徑及往內變細的段落，找第一次增粗的起點。斜線由兩端點確定起點；垂直階差則直接取該 Y，不需要先走過一個掃描間距才發現變化。

增粗以整段累積半徑增加量超過座標容差後確認，回取該次增粗的原始起點；不能逐小段套用容差而漏掉緩坡。往內重新變細時重新尋找增粗，浮點捨入誤差不視為轉折。座標容差、最小預留長度及策略一致性容差由 [config/analysis.ts](../../../src/config/analysis.ts) 管理；其中一致性容差不是取樣間距。

首次增粗起點距該端不足最小預留長度時，回報該端無法判斷，不另選更內側的增粗代替。切點再加上校準內的兩端修正；缺端、順序不合法、超出範圍或不同策略矛盾時停止體積計算，保留可用診斷／部分切點。此策略判斷幾何交界，不另外辨識完整球棒主體或保證任意尾料都能對應實物成品邊界；驗證界線見 [測試與驗證](../建置、驗證與運維/測試與驗證.md#計算驗證界線)。

[clipProfile](../../../src/domain/geometry/volume.ts) 將切點套回完整邊界：保留中間轉折、內插邊界半徑；切點恰落在垂直階差時，低端用右側、高端用左側，保留區內的形狀。相同 Y 的階差長度為零，不增加體積。

## 體積與尺寸

體積以相鄰輪廓點的圓台公式積分：

`V = Σ π × L × (r₁² + r₁r₂ + r₂²) / 3`

內部為 mm³，轉 cm³ 時除以 1000；對目前線性半徑段直接積分，不從顯示網格或四捨五入數字反算。尺寸入口為 [dimensions.ts](../../../src/domain/geometry/dimensions.ts)：

- 長度：裁切輪廓兩端的 Y 差。
- 棒頭直徑：裁切輪廓最大半徑乘二。
- 握把直徑：先由 [握把策略](../../../src/domain/grip/knob-valley.ts) 判斷較細端、棒尾凸起及內部低谷，取得語意區域，再量該區最小直徑。不是整枝球棒任意位置的全域最小值。

握把策略使用按長度加權的端部平均半徑，不以點數比例決定棒型。搜尋邊界、凸起與恢復、低谷矛盾等檢查失敗時，握把標成無法判斷，已成功的體積、長度及棒頭直徑保留。策略參數集中在 `gripParameters`，不改變切線或扣除棒尾凸起。

## 端面量測距離

量測基準是裁切後的完整輪廓，由共用尺寸計算產生，不從 3D 顯示網格找位置，也不要求使用者設定原點：

- 棒頭位置：從棒頭裁切端面往內，量到棒頭直徑所在處。
- 握把位置：從棒尾裁切端面往內，量到已辨識握把區域內的握把直徑所在處。

棒頭／棒尾依握把策略辨識的端向決定，不固定綁在低 Y 或高 Y。只有握把端向及區域成功辨識時才提供這兩種距離；失敗時兩者皆為未知，仍保留可用的棒頭直徑。反向或平移 ANC 座標不改變距離語意。

位置沿完整線段與轉折量測，沒有固定格線。單點回傳單值；連續等粗段回傳起訖範圍；被其他粗細隔開的同值位置各自保留，不能連成一個區間。等粗判斷只吸收浮點捨入誤差，不把真實緩坡當成平台。內部保留完整 mm 起訖值，從端面往內為正，端面本身為 0。

## 原始數值與顯示

幾何保存 mm，重量保存 g，計算與排序使用完整數值。[format.ts](../../../src/lib/format.ts)、[length-display.ts](../../../src/lib/length-display.ts)、[weight-display.ts](../../../src/lib/weight-display.ts)、[measurement-display.ts](../../../src/lib/measurement-display.ts) 管理畫面與報告格式：

| 欄位 | 呈現規則 |
| --- | --- |
| 體積 | cm³，顯示整數 |
| 棒頭直徑／握把直徑 | mm，顯示一位小數 |
| 端面量測距離 | cm，固定兩位小數、四捨五入；連續區間以「～」、分離位置以「、」分隔，未知為 — |
| 長度 | cm 一位小數，或 in 取最近 0.25 吋，或兩者；桌面單支詳情固定顯示同一 0.25 吋取位的 in |
| 重心距棒尾 | cm 或 in，單一單位、小數一位；按原始距離排序 |
| MOI | kg·cm² 或 oz·in²，單一單位、整數及千分位；範圍顯示上下限，按原始數值排序 |
| 預計球棒重量 | 固定 g，顯示整數；要求重量輸入也使用 g |
| 木料重量 | 依偏好 g 整數、oz 一位小數，或 oz 主行／g 次行 |
| 切點座標 | mm，依座標格式顯示最多兩位小數 |

長度顯示的英吋取位不改原始 mm，oz 換算不改保存的 g；未修改的重量輸入可重用原值，避免來回換算損失精度。量測距離同一區間的兩端顯示值相同時呈現單值，原始區間仍保留。Excel 數字與文字輸出的差異見 [報告與列印](報告與列印.md)。

棒頭與握把直徑直接使用分析結果，畫面與報告只在顯示時取位；排序與分組保留原始精度。

## 材料與重量公式

唯一公式核心是 [weight.ts](../../../src/domain/weight.ts)。令 Vb 為裁切後球棒體積、Vm 為木料體積、Wm 為木料實測重量、e 為百分比誤差，修正係數 `f = 1 + e / 100`。密度單位 g/cm³，體積 cm³，重量 g。

1. Vm、Wm 都有效時，採 `ρ = Wm / Vm`；否則使用參考密度。兩者都沒有有效值時不猜密度。
2. 未指定要求重量：預計球棒重量為 `Vb × ρ × f`。
3. 已指定要求重量：預計重量欄顯示提交的上下限，不再乘 f；所需木料重量上下限分別為 `要求重量 × Vm / Vb / f`，不需要密度。
4. 未指定要求時，木料欄使用輸入的 Wm，否則由 `Vm × ρ` 得到參考重量；不是反推值。

體積、密度及重量需為正有限值；誤差需大於 −100%，null 視為 0%。反推缺少有效球棒／木料體積時不產生結果，Vm 小於 Vb 時回報木料體積不足。校正不改材料實測值或球棒幾何；兩種模式各使用一次 f。

要求重量輸入由 [weight-input.ts](../../../src/features/batch/weight-input.ts) 正規化：兩個正值會按大小排序，填反時自動交換。

設定初始值與保存位置集中記錄於 [資料保存與設定](資料保存與設定.md)。實物密度分布、含水率或打磨影響不在目前幾何公式內。

## 成品重心與 MOI

[mass-properties.ts](../../../src/domain/geometry/mass-properties.ts) 在分析階段使用裁切後完整輪廓，按實心、軸對稱及均勻密度模型求重心與每單位質量的慣性。沿線性半徑段積分，包含棒身橫截面對垂直轉軸的慣性，不將整支棒視為集中在重心的單一質點，也不從 3D 網格取樣。

重心距離從成品棒尾裁切端面量起。MOI 的參考軸通過棒軸上距該端面 152.4 mm 處，並垂直於棒長。棒尾端向沿用成功的握把辨識；無法辨識時仍保留幾何重心與標記，但距棒尾數值及此參考軸的 MOI 為未知，不猜方向。

[bat-properties.ts](../../../src/domain/bat-properties.ts) 統一套用目前重量：未指定時使用已含重量修正的預估值，指定時使用指定值或上下限，不重複修正。指定重量表示該外形達到此重量時的預測，不代表實測；同棒型的 MOI 與總質量成正比，重心不變。沒有可用重量時，重量與 MOI 顯示 —，重心仍可計算。

計算中的幾何使用 mm，MOI 結果使用 kg·m²；畫面與報告最後才換算並四捨五入。排序、重心環線及後續計算使用完整精度。重心單位切換不套用棒長的 0.25 吋取位。均勻密度及未完成實機校準的限制同樣適用，顯示位數不代表實體精度。
