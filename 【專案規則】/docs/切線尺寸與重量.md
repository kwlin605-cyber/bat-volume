# 切線、尺寸與重量

## 切線與裁切

統一入口為 [analyze.ts](../../src/domain/analyze.ts)。有刀寬與 0 mm 模式都直接將完整輪廓交給切線策略；沒有固定間距掃描，也不將交界吸附到格線。

[terminal-stubs.ts](../../src/domain/cuts/terminal-stubs.ts) 的 `terminal-first-rise` 規則分別從低 Y、高 Y 端往內檢查，略過定半徑及往內變細的段落，找第一次增粗的起點。斜線由兩端點確定起點；垂直階差則直接取該 Y，不需要先走過一個掃描間距才發現變化。

增粗以整段累積半徑增加量超過座標容差後確認，回取該次增粗的原始起點；不能逐小段套用容差而漏掉緩坡。往內重新變細時重新尋找增粗，浮點捨入誤差不視為轉折。座標容差、最小預留長度及策略一致性容差由 [config/analysis.ts](../../src/config/analysis.ts) 管理；其中一致性容差不是取樣間距。

首次增粗起點距該端不足最小預留長度時，回報該端無法判斷，不另選更內側的增粗代替。切點再加上校準內的兩端修正；缺端、順序不合法、超出範圍或不同策略矛盾時停止體積計算，保留可用診斷／部分切點。此策略判斷幾何交界，不另外辨識完整球棒主體或保證任意尾料都能對應實物成品邊界；驗證界線見 [測試與驗證](測試與驗證.md#計算驗證界線)。

[clipProfile](../../src/domain/geometry/volume.ts) 將切點套回完整邊界：保留中間轉折、內插邊界半徑；切點恰落在垂直階差時，低端用右側、高端用左側，保留區內的形狀。相同 Y 的階差長度為零，不增加體積。

## 體積與尺寸

體積以相鄰輪廓點的圓台公式積分：

`V = Σ π × L × (r₁² + r₁r₂ + r₂²) / 3`

內部為 mm³，轉 cm³ 時除以 1000；對目前線性半徑段直接積分，不從顯示網格或四捨五入數字反算。尺寸入口為 [dimensions.ts](../../src/domain/geometry/dimensions.ts)：

- 長度：裁切輪廓兩端的 Y 差。
- 最大直徑：裁切輪廓最大半徑乘二。
- 最細握把：先由 [握把策略](../../src/domain/grip/knob-valley.ts) 判斷較細端、棒尾凸起及內部低谷，取得語意區域，再量該區最小直徑。不是整枝球棒任意位置的全域最小值。

握把策略使用按長度加權的端部平均半徑，不以點數比例決定棒型。搜尋邊界、凸起與恢復、低谷矛盾等檢查失敗時，只將握把標成無法判斷，已成功的體積、長度及最大直徑保留。策略參數集中在 `gripParameters`，不改變切線或扣除棒尾凸起。

## 原始數值與顯示

幾何保存 mm，重量保存 g，計算與排序使用完整數值。[format.ts](../../src/lib/format.ts)、[length-display.ts](../../src/lib/length-display.ts)、[weight-display.ts](../../src/lib/weight-display.ts) 管理畫面與報告格式：

| 欄位 | 呈現規則 |
| --- | --- |
| 體積 | cm³，顯示整數 |
| 最大直徑／握把直徑 | mm，顯示一位小數 |
| 長度 | cm 一位小數，或 in 取最近 0.25 吋，或兩者；桌面單支詳情的尺寸摘要目前固定顯示 cm |
| 預計球棒重量 | 固定 g，顯示整數；要求重量輸入也使用 g |
| 木料重量 | 依偏好 g 整數、oz 一位小數，或 oz 主行／g 次行 |
| 切點座標 | mm，依座標格式顯示最多兩位小數 |

長度顯示的英吋取位不改原始 mm，oz 換算不改保存的 g；未修改的重量輸入可重用原值，避免來回換算損失精度。Excel 數字與文字輸出的差異見 [報告與列印](報告與列印.md)。

[直徑扣除量](../../src/domain/diameter-allowance.ts) 扣的是整個直徑，不是半徑。先扣再顯示；結果不大於零時顯示未知。它只改顯示尺寸及直徑欄排序，不改完整輪廓、體積、重量、3D 或原始直徑分組。

## 材料與重量公式

唯一公式核心是 [weight.ts](../../src/domain/weight.ts)。令 Vb 為裁切後球棒體積、Vm 為木料體積、Wm 為木料實測重量、e 為百分比誤差，修正係數 `f = 1 + e / 100`。密度單位 g/cm³，體積 cm³，重量 g。

1. Vm、Wm 都有效時，採 `ρ = Wm / Vm`；否則使用參考密度。兩者都沒有有效值時不猜密度。
2. 未指定要求重量：預計球棒重量為 `Vb × ρ × f`。
3. 已指定要求重量：預計重量欄顯示提交的上下限，不再乘 f；所需木料重量上下限分別為 `要求重量 × Vm / Vb / f`，不需要密度。
4. 未指定要求時，木料欄使用輸入的 Wm，否則由 `Vm × ρ` 得到參考重量；不是反推值。

體積、密度及重量需為正有限值；誤差需大於 −100%，null 視為 0%。反推缺少有效球棒／木料體積時不產生結果，Vm 小於 Vb 時回報木料體積不足。校正不改材料實測值或球棒幾何；兩種模式各使用一次 f。

要求重量輸入由 [weight-input.ts](../../src/features/batch/weight-input.ts) 正規化：兩個正值會按大小排序，填反時自動交換。

設定初始值與保存位置集中記錄於 [資料保存與設定](資料保存與設定.md)。實物密度分布、含水率或打磨影響不在目前幾何公式內。
