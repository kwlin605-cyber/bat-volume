# 手機與電腦操作

## 共用入口與響應式

[App.tsx](../../src/App.tsx) 以 [desktopQuery](../../src/config/analysis.ts) 的 1024 px 斷點分流，同一份批次、材料與單位狀態傳給兩種介面。沒有另一個手機後端或計算核心。

| 操作 | 電腦寬度 | 手機寬度 |
| --- | --- | --- |
| 上傳 | 可選多檔，加入目前批次 | 使用第一個檔案，清除舊批次後取代 |
| 內建型號 | 彈窗選取／取消加入，可瀏覽廠商與分類資料夾 | 底部抽屜單選，選取後關閉並取代目前批次 |
| 結果 | 一支也使用表格，點檔名看單支詳情 | 顯示批次最後一支的資料卡 |
| 要求重量 | 表格選取後共用浮動編輯框，可批次套用 | 單支重量輸入 |
| 報告 | 顯示欄位、排序、下載與報告預覽 | 不提供桌面批次報告操作 |
| 3D | 單支詳情內顯示 | 點入口後才載入，全螢幕呈現 |

由桌面切到手機不會只因斷點改變而刪除其他檔案；手機再選新型號／檔案時才按替換流程清空原批次。移除目前最後一支後可露出前一支；最後一支被移除才回到空狀態。

兩種型號庫都依完整來源判斷「已加入」，不同廠商／資料夾的同名項目互不連動，手動上傳不會勾選同名型號。電腦再次點選已加入來源會移除對應資料列；手機維持單選替換。選取先建立載入中的結果項目，讀檔與分析由共用佇列負責，關閉型號庫不會取消已加入項目。

## 電腦表格

[batch-results.tsx](../../src/features/batch/batch-results.tsx) 使用 [buildBatchView](../../src/features/batch/view-model.ts) 的資料，欄位由 `columns.ts` 管理、內容欄寬由 `column-layout.ts` 與 `use-column-layout.ts` 量測。檔名／原因靠左，數值置中；預計重量為主要視覺。過寬時允許水平捲動，不為塞入資料而無限縮小數字。

目前批次有重複的顯示檔名時，這些列才在檔名旁加灰階圓角來源標籤；空間不足自動換行，不增加欄位。來源顯示廠商／完整資料夾，手動上傳與舊無來源資料各自標示「手動上傳」及「來源不明」。計數包含載入中或分析失敗的項目；只剩一支或不再同名時隱藏。原本診斷仍在下方獨立呈現，不改成來源標籤或統一的失敗文字。列選取、重量控制、檔名預覽與移除按鈕的可存取名稱同樣包含需要區分的來源。

「顯示資訊」中的「量測距離」是一個共用開關，控制棒頭直徑與握把直徑兩欄內的次行資訊，不增加欄位；各欄仍可獨立隱藏。距離定義與取位見 [端面量測距離](切線尺寸與重量.md#端面量測距離)，初始值與保存相容性見 [資料保存與設定](資料保存與設定.md#初始值與來源)，輸出差異見 [報告與列印](報告與列印.md)。

顯示欄位可隱藏、排序可升降；棒壘分類使用原始棒頭直徑，低於分界為壘球、大於或等於為棒球，未知放最後。這是可調分類，不是官方辨識。組內依完整數值排序，範圍先比下限再比上限；數值同值依檔名自然排序，未知數值置後。未填要求且組內木料參考值全相同或全未知時，沿用檔名自然升冪。

表格要求選取由 [row-selection.ts](../../src/features/batch/row-selection.ts) 與 [use-row-selection.ts](../../src/features/batch/use-row-selection.ts) 管理：一般點擊單選、Ctrl 加減選取、Shift 依錨點選範圍、Ctrl＋Shift 保留其他選取。拖曳可連續選取並在邊緣捲動，放開才顯示編輯框。一般點檔名看預覽，搭配 Ctrl／Shift 則參與選取。

單支帶入既有要求，多支草稿保持空白；下限按 Enter 移到上限，第二次 Enter 才提交。Esc、點外面或取消會放棄未提交草稿，已套用要求保持原值；既有單支可清除要求。上下限實際正規化方式以 [重量文件](切線尺寸與重量.md) 為準。

垃圾桶切換移除模式，按列旁 × 立即移除該支；勾勾退出。選取、浮動框及移除工具不出現在匯出報告。更改排序、部分檔案清單或移除模式會結束暫時選取。

## 電腦單支預覽

[result-dialog.tsx](../../src/features/batch/result-dialog.tsx) 只在彈窗標題列顯示檔名，左側資訊卡從狀態、體積及尺寸開始。直徑數值與單位靠右，對齊長度；端面距離標籤在同列左側，窄版時標籤文字可換行，主數值維持在右。單支距離資訊不受表格開關控制。

標題列的模式切換水平對齊右側 3D 預覽區中心，關閉鈕在最右；長檔名省略顯示並保留完整標題提示。標題與內容沿同一份欄寬設定排列，畫布上下對齊左側資訊框，展開切線位置時一起調整高度。

## 手機卡片

[mobile-result-view.tsx](../../src/components/mobile-result-view.tsx) 顯示預計重量／木料重量、四項幾何資訊、切點詳情及 3D 入口。材料、單位與要求仍回寫同一 App/session，避免與桌面各存一份。

手機結果卡不加來源標籤；來源仍隨資料保存，型號庫的「已加入」也保留完整來源識別。

長度雙單位時，英吋小字對照在左、公分主數值與單位在右，沿用下方直徑數值樣式。單一單位維持單值呈現。主要卡片之間及尺寸卡到 3D 入口保留一致間距；小型控制擴大觸控範圍，型號庫與木料設定沿用各自的返回及套用流程。

手機重量編輯與桌面不同：下限有效後可移至上限，未填上限時沿用下限；離開整個輸入區時，非空且有效的草稿會提交，空白則取消。Esc 取消；清除移除已提交要求。文件不把桌面「點外部取消」套到手機。

直徑扣除量大於 0 時才顯示卡片上的調整提示；為 0 時仍可從木料設定進入。卡片與桌面共用公式，不因介面不同更改密度或重量單位的含義。

## 3D 與失敗狀態

[bat-preview.tsx](../../src/components/bat-preview.tsx) 共用兩端的模型呈現；[preview-mode.tsx](../../src/components/preview-mode.tsx) 提供模式狀態與切換元件，由各預覽視窗持有當次狀態。按鈕左為「預計切除」、右為「整枝」，每次開啟預設切除，不記住上次選擇。無法計算切除結果時停用切除並使用整枝；若仍有輪廓，可顯示整枝或部分切點。

[bat-geometry.ts](../../src/components/bat-geometry.ts) 將對應的完整／裁切輪廓旋轉一圈並封端，圓周目前 96 段，沒有額外簡化軸向形狀。切割虛線只在整枝模式顯示；棒頭與已辨識握把的位置細線保留，沒有跟隨模型的直徑文字標籤。兩種模式下方都只保留無白底的操作提示。這個網格只呈現外形，不回算體積。

手機 [mobile-preview-dialog.tsx](../../src/components/mobile-preview-dialog.tsx) 將檔名、模式切換及關閉鈕放在同一標題列；切換鈕保留小巧外觀與較大的透明點擊範圍。下方棒頭／握把量測左右並排，直徑大字、距離在各自下方，沿用共用格式。畫布占標題與量測資訊之間的可用空間，能延伸到操作提示後方，超出畫布邊界才裁掉；矮畫面可捲到量測資訊。

電腦為左鍵旋轉、右鍵平移、滾輪縮放；手機為單指旋轉、雙指平移／縮放。[preview-controls.tsx](../../src/components/preview-controls.tsx) 沿用同一個 OrbitControls，以畫布高度補償套件的高度正規化；[config/preview.ts](../../src/config/preview.ts) 統一靈敏度與阻尼。旋轉基準為每拖動一個 CSS px 轉 0.3°，即 100px 約 30°，框高變動不改最終轉角；阻尼讓拖動與放手收尾平順，不另改平移與縮放速度。初始視角自動將模型完整放入畫布，兩端共用同一留白設定。

3D 仍按需載入，載入提示與 [PreviewBoundary](../../src/components/preview-boundary.tsx) 隔離沿用現有文字。模式切換位於畫布外，載入中仍可操作；手機下方量測資料不因 WebGL 失敗而消失。

未知數值顯示 —，可判斷的幾何仍保留；診斷由 `i18n/zh-TW.ts` 對應。載入、失敗與空清單不是同一狀態。視覺與元件擴充要求見 [UIUX 設計規範](UIUX設計規範.md)。

型號來源不可用時只顯示移除或載入失敗提示，沒有可用輪廓或 3D 入口；與 ANC 已讀取但無法判斷切線的情況分開。已提交要求及重開恢復方式見 [資料保存與設定](資料保存與設定.md#來源解析與重開計算)。
