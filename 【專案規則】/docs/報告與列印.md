# 報告與列印

## 共用資料與入口

桌面 [BatchResults](../../src/features/batch/batch-results.tsx) 以 [buildBatchView](../../src/features/batch/view-model.ts) 組合欄位、排序、棒壘分類、重量與顯示格式；報告開啟時取得該份 view。報告不讀表格 DOM、不重新計算 ANC 或另一套重量，也不把選取底色、浮動框與移除工具帶進輸出。

[columns.ts](../../src/features/batch/columns.ts) 管理欄位語意，[column-layout.ts](../../src/features/batch/column-layout.ts) 提供內容欄寬計算；網頁、PDF 與 Excel 按各自字型及限制提供量測參數。檔名與原因靠左，其餘數值置中；預計重量使用較大字級與強調底色。檔名與診斷可完整換行，長內容與多頁不能靠裁掉資料處理。

[report-preview-dialog.tsx](../../src/features/batch/report-preview-dialog.tsx) 管理當次預覽、縮放、頁碼、下載及取消。[formats.ts](../../src/reports/formats.ts) 定義 Excel A4 直式、PDF A4 直式與橫式；renderer 按需載入，ExcelJS 不隨手機主畫面先載入。

同名來源的顯示判斷沿用 [桌面 BatchView](手機與電腦操作.md#電腦表格)，不由各 renderer 再比對檔名。[report-view.ts](../../src/reports/report-view.ts) 保留 PDF 的來源標示，為 Excel 移除該呈現欄位後再量測與預覽；不改任何幾何、重量或排序值。

## 排版、分頁與縮放

| 層級 | 來源與責任 |
| --- | --- |
| 內容欄寬、換行、列高 | [report-layout.ts](../../src/reports/report-layout.ts) |
| A4、分頁與每頁定位 | [pdf-layout.ts](../../src/reports/pdf-layout.ts) |
| 分組比例、自動縮放與翻頁銜接 | [print-preview.ts](../../src/reports/print-preview.ts) |
| 紙張、字體、邊界與比例範圍 | [config/report.ts](../../src/config/report.ts)、[pdf.ts](../../src/config/pdf.ts)、[excel.ts](../../src/config/excel.ts) |
| 畫面／PDF 共用繪製 | [report-rendering.ts](../../src/reports/report-rendering.ts)、[report-canvas.ts](../../src/reports/report-canvas.ts) |

每次預覽初始 100%，比例允許 25–200% 的整數，紙張與 5 mm 最小邊界固定；字級、欄寬及列高隨比例改變。每頁由表頭開始，重複表頭，整頁資料依自身大小水平及垂直置中，不另加報告標題或日期。PDF／預覽只畫資料列之間的橫線，該頁最後一列下方不再畫線。

棒壘分頁初始開啟，依目前分類與排序讓各組從新頁開始；未知分類接在最後一組，放不下才續頁，不另創一套分類。只有一組時不產生多餘空白頁。關閉分頁則連續列印，不改主網頁表格。

- 手動模式：開啟分組時可逐組調整，翻頁顯示該組比例；改比例只影響所屬組，退出自動模式。關閉分組時使用當前頁比例，重新開啟以統一比例起始。
- 維持頁數最大尺寸：以目前分頁模式在 100% 的頁數為基準，找不超寬且不增加頁數的最大比例。分組時各組分開計算，不互借頁數。
- 縮成一頁：不分組時整批一頁，分組時各組各一頁，搜尋可用範圍內的最大比例；最小比例仍放不下時提示，不裁資料。

兩個自動縮放模式互斥，切換分頁會依目前模式重新計算。「縮成一頁」再次點擊回到手動比例；最大尺寸按鈕只啟用該模式，手動修改比例可退出自動模式。這些狀態只屬於當次預覽，不保存到批次或 localStorage。

## PDF

[pdf-report.ts](../../src/reports/pdf-report.ts) 使用共用分頁座標與頁面繪製結果，將每頁以 216 dpi 無損影像放進 PDF。中文字型由裝置提供，不另下載字型；PDF 文字不是可選取／可編輯的原生文字。逐頁讓出主執行緒，關閉預覽可取消尚未完成的輸出。

來源以灰階圓角標籤呈現，與網頁使用 [共用標籤比例](../../src/config/source-tag.ts)。同欄空間足夠時與檔名並排，否則放在檔名下方；原診斷另起文字區塊。長來源可換行並隨列延續至後頁，內容與數據不能因標籤而被裁掉；預覽與下載共用相同排版及繪製。

## Excel

[excel-report.ts](../../src/reports/excel-report.ts) 以同份 view 及排版設定建立原生儲存格，使用 Segoe UI，中文回退 Microsoft JhengHei。表頭凍結、列印重複表頭、A4 直式、上下左右置中；字級與尺寸已套用預覽比例，原生列印比例保持 100%，不再啟用 fit-to-page 二次縮放。

Excel 不放來源標籤或來源文字，預覽與下載都不為來源保留額外欄寬或列高；檔名、原診斷與數值仍依既有方式輸出。同名型號在工作簿內不另外區分來源，這是目前輸出契約。

體積、cm 長度、直徑、單一重量以完整精度數字儲存，再以格式呈現小數位；單英吋長度依共用 0.25 吋取位寫入。重量範圍或雙單位同格多行以文字／rich text 保留，未知值為 —；不能聲稱所有 Excel 欄位都是未取位的數字。對應邏輯為 `reportCellValue` 與 `reportCellNumberFormat`。

有兩組且啟用棒壘分頁時，各組需要獨立欄寬及字級，因此輸出兩張工作表；尾端未知留在最後一張。列印兩組需選整本活頁簿。Excel 的字型、換行及印表機會影響實際分頁，網站預覽的頁數僅供參考。

## 下載與驗證

[download.ts](../../src/reports/download.ts) 統一建立檔名、Blob URL 與下載後釋放；日期用於檔名／工作簿 metadata，不代表表格頁面會顯示日期。前端列印預覽與 PDF 共用實際排版，Excel 套用其尺寸但不保證由不同列印引擎產生相同頁數。

自動保護與實際列印界線見 [測試與驗證](測試與驗證.md)。修改共用排版時須核對兩種 renderer、分組、未知值、長檔名、範圍／雙單位、不同縮放與關閉取消，不只看單頁少量資料。
