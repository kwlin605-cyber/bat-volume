# 廠商 ANC 球棒庫「按需動態載入」與雙端響應式介面升級規劃

本規劃整合「**Vite 編譯期自動目錄掃描 + 按需動態載入**」技術，並同步重構**手機版與電腦版 UI/UX**：電腦版維持強大多球棒批次對比總表；手機版全面翻新為「專注單支數據」介面，將球棒重量與木料重量作為核心視覺焦點，3D 外形採點擊彈出式，並打通單位切換與材質設定。

---

## 審查確認與關鍵決策點

> [!IMPORTANT]
依據與您的深入討論，以下為全案確認的核心規格與設計共識：

- **檔案架構與掃描機制**：
  檔案收納於 `src/assets/anc/<廠商名稱>/<型號名稱>.anc`。使用 Vite 內建 `import.meta.glob` 在打包階段自動建立「廠商 → 型號」兩層目錄清單。新檔案直接丟入目錄即可，零代碼維護。
- **動態載入與相容性**：
  首頁不打包任何 `.anc` 文本內容，點選時才非同步抓取並封裝成標準 `File` 物件，**100% 複用現有 Web Worker 幾何計算核心與 IndexedDB 本地快取**。
- **三向自由混用**：
  「手動上傳本機檔案」、「專案內廠商庫選取」與「瀏覽器記憶暫存」三者完全並存、自由混用。
- **手機版介面設計（採方案 A：全顯示 + 一鍵換單位）**：
  - **專注單支數據**：不硬塞複雜橫向寬表，以清晰直覺的卡片呈現單支球棒。
  - **核心視覺主角**：比照電腦版風格，以大字體高亮顯示「**球棒預估重量**」與「**木料素材重量**」；未設定木料時顯示友善引導按鈕，點擊可快速設定密度/木種。
  - **基礎幾何尺寸**：總長度、最大外徑、握把最細徑、體積整齊排列於下方。
  - **3D 外形預覽**：平時不佔用版面，在右上角提供【📐 3D 外形】按鈕，點擊才彈出全螢幕 3D 視圖。
  - **換棒操作**：提供底部抽屜（Bottom Sheet）讓大拇指輕鬆滑動挑選廠商與型號。
- **電腦版介面**：
  維持既有強大多球棒橫向批次大總表，新增彈窗式型號庫（左側廠商、右側型號卡片）。

## 1. 概念與核心價值 (Overview & Core Concept)

- **核心功能**：
  建構完全靜態（Serverless Jamstack）、零後端依賴的球棒 CNC 檔案庫。支援工程師與現場師傅即開即用，免去找檔案上傳的繁瑣步驟，同時保留自訂上傳與對比分析彈性。
- **目標場景**：
  - **辦公室/設計端（電腦）**：一次開啟數十支球棒進行公差比對、規格分組、批量匯出 Excel/PDF 報表。
  - **工廠現場/機台旁（手機）**：拿著手機快速查驗特定型號的外徑公差、確認木料素材重量是否足夠、查看切削外形。

### 手機版視覺層次 (Mobile Layout Hierarchy)

1. **頂部導覽列（Sticky Top Bar）**：
   - 顯示當前球棒名稱（如 `Mizuno-Pro-84cm.anc`）。
   - 右側快捷按鈕：【🔄 更換球棒】與【📐 3D 外形】。
2. **核心重量卡片（Visual Prominence）**：
   - **已設定木料時**：
     - 左側：**預估球棒重量**（大字體，如 `855 g` / `30.2 oz`，點擊即時切換單位）。
     - 右側：**木料素材重量**（如 `1,020 g`）。
   - **未設定木料時**：
     - 顯示優雅的導引卡片：`未設定木料 ⚙️ 點此選擇木種或密度計算重量`。
3. **基礎幾何尺寸卡片（Dimensions Block）**：
   - **總長度**：`84.0 cm`（支援一鍵切換 `inch`）。
   - **最大外徑**：`64.2 mm`（計入公差）。
   - **握把最細徑**：`23.1 mm`（計入公差）。
   - **保留體積**：`812.5 cm³`。
4. **輔助操作列**：
   - 【⚙️ 木料與直徑公差】：在手機上調整公差（例如 +0.2mm）與木材密度。
   - 【📤 上傳我的檔案】：支援隨時改用本機檔案計算。

## 4. 實作計畫 (Implementation Steps)

1. **建立目錄與分類 ANC 樣本**：
   - 建立 `src/assets/anc/` 目錄，規劃廠商子目錄（如 `美津濃`、`ZETT` 等），收納具代表性之 `.anc` 範本。
2. **型號庫目錄索引模組 (`src/services/anc-catalog.ts`)**：
   - 使用 `import.meta.glob('/src/assets/anc/*/*.anc', { query: '?raw', import: 'default' })` 自動解析目錄。
   - 提供依廠商分組、關鍵字搜尋及非同步載入為 `File` 物件之工具方法。
3. **手機版專屬組件開發 (`src/components/mobile-result-view.tsx`)**：
   - 實作手機專屬單支視圖：頂部球棒名稱、大字體重量視覺卡片、未設定木料提示引導、基礎尺寸表。
   - 整合單位切換（g ↔ oz、cm ↔ inch）。
   - 實作彈出式全螢幕 3D 外形視圖（可點開/關閉）。
4. **手機底部抽屜與電腦彈窗選單**：
   - 手機端：底部滑出抽屜（支援廠商標籤橫向滑動、即時搜尋、大觸控項目）。
   - 電腦端：雙欄居中彈窗（左側廠商、右側卡片列表）。
5. **整合進 `App.tsx` 與既有狀態**：
   - 雙端空狀態新增【選擇球棒型號】按鈕。
   - 手機版載入單支球棒時無縫套用木料設定與公差計算。
6. **編譯測試與功能驗證**：
   - 執行 `compile_applet` 確保 TypeScript 編譯無誤。
   - 驗證手動上傳與廠商庫檔案切換、IndexedDB 暫存持久化與響應式切換。
