# 球棒體積

從 CNC `.anc` 程式估算球棒加工後的外形、切線、保留體積、長度與直徑，支援重量預估、反推所需木料重量及 3D 預覽。內建型號按需載入，也能上傳自己的 ANC；檔案分析與資料保存都在目前瀏覽器執行。

電腦版提供多檔表格、批次指定重量、排序、分組及 Excel／PDF 報告；手機版提供單支資料卡、重量設定與按需開啟的 3D。兩者使用同一份分析核心與材料設定。

## 本機使用

已經建置過時，雙擊 [啟動.cmd](啟動.cmd) 即可。啟動檔只提供 `dist` 裡已編譯的網站，不會自動重新編譯；修改程式或內建 ANC 後，先執行 `npm run build` 再開啟或重新整理網站。型號庫與手動上傳的重開載入方式見 [資料保存與設定](【專案規則】/docs/功能、資料與契約/資料保存與設定.md)。

第一次準備開發環境時，使用 Node.js 24（與 Actions 一致），在專案根目錄執行：

```sh
npm ci
npm run build
```

開發預覽使用 `npm run dev`。更多本機服務、網址與 GitHub Pages 的差異見 [啟動建置與部署](【專案規則】/docs/建置、驗證與運維/啟動建置與部署.md)。

## 計算重點

預設以 5 mm 平刃鋸片、Y 為刀寬中心、Z 為半徑建立完整掃掠輪廓；多趟加工重疊處取切得最深的結果。切點直接由完整輪廓兩端往內找第一次變粗的起點，不使用固定間距掃描。裁切後的輪廓供尺寸、體積與切除後 3D 使用，重量推算再使用其體積。這些是程式幾何假設，實機刀具基準與切割位置仍需校準。
